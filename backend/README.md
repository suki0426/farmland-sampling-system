# 基于GIS的农田土壤智能采样与导航系统

## 项目简介

本项目面向智慧农业土壤采样场景，计划实现农田 GIS 管理、智能采样点规划、多终端实时数据上传、路径规划、现场采样记录、历史数据分析等功能。

## 技术栈

### 前端

- Vue 2
- Element UI
- ECharts
- 高德地图 JS API

### 后端

- Java 8
- Spring Boot
- MyBatis-Plus
- MySQL
- Redis

### 设备模拟

- Python
- UDP Socket
- NMEA0183
