# 基于GIS的农田土壤智能采样与导航系统（前端）

本目录为 Vue 2 前端工程。当前阶段仅完成稳定骨架与构建验证，农田 GIS、智能采样、路径导航等业务功能将在后续分支中开发。

## Business Rules

- Teaching document edit/manual entry page only provides `保存`; it does not provide a publish action.
