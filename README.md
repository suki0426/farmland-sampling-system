# 基于GIS的农田土壤智能采样与导航系统

## 项目简介

本项目面向智慧农业土壤采样场景，融合 GIS、GNSS、多终端实时通信、智能采样点规划和路径优化，实现农田管理、三终端实时数据上传、中央接收、采样导航、现场记录、历史分析和报表等功能。

## 技术栈

### 前端

- Vue 2
- Element UI
- ECharts
- 高德地图 JS API

### 后端

- Java 8
- Spring Boot
- MyBatis-Plus
- MySQL
- Redis

### 设备模拟

- Python
- UDP Socket
- NMEA0183

## 项目结构

- `backend/`：Java 后端
- `frontend/`：Vue 前端
- `simulator/`：三台采样终端模拟器
- `docs/`：环境、接口、协议和协作文档
