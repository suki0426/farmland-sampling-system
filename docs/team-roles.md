# 团队角色与职责

## 组长 / 后端集成

- 分支：`feature/backend-integration`
- 负责：Spring Boot、Controller / Service、公共 API、数据接收整合、各模块接口连接、Git / PR、每日集成、最终联调。

## 前端 GIS

- 分支：`feature/frontend-gis`
- 负责：Vue 2、Element UI、高德地图、农田 Polygon、采样点 Marker、三个终端实时位置、路线显示、页面交互与状态显示。

## 设备通信

- 分支：`feature/device-communication`
- 负责：Python、三台设备模拟、UDP、NMEA / GNSS、约 100 条实时数据、三条不同移动轨迹。

## 采样算法

- 分支：`feature/sampling-algorithm`
- 负责：规则网格、Point-in-Polygon、蛇形路线、Nearest Neighbor。
- 核心稳定以后再做：2-opt。

## 数据库与数据分析

- 分支：`feature/database-analysis`
- 负责：MySQL、SQL、索引、历史数据、统计数据、ECharts。
- 核心稳定以后再做：Excel 报表。
